# Мини-МИС — учебный проект воркшопа

- Учебное веб-приложение поликлиники. Каждый модуль — вкладка в `index.html`.
- **Только синтетические данные.** Никаких реальных ФИО, СНИЛС, адресов, диагнозов.
- Стек: чистый JavaScript (ES-модули), без сборки и без зависимостей. Не добавлять npm-пакеты.
- Модуль `<id>` состоит из двух файлов:
  - `src/<id>.js` — логика, чистые функции, без DOM;
  - `src/<id>.ui.js` — экспортирует `mount(container)`, рисует форму во вкладке.
- Тесты: `node:test` + `node:assert/strict`, файлы `test/*.test.js`, запуск `npm test`.
- Запуск приложения: `npm start` → http://localhost:3000.
- Интерфейс и сообщения — на русском.
- Изменения ведём через OpenSpec: сначала предложение и спецификация (`openspec/changes/`), потом код.
