# Proposal

## Why

Поликлиника принимает заявки на вызов врача на дом по телефону и вручную определяет дату визита. Нужен модуль «Мини-МИС», который регистрирует заявку, назначает дату визита по правилу отсечки и не даёт зарегистрировать вызов, когда пациенту нужна скорая помощь.

## What Changes

- Новая вкладка «Вызов врача на дом» с формой: ФИО, участок (1–5), время заявки, жалобы флажками.
- Логика регистрации заявки: проверка полей, отказ при «красных флагах», расчёт даты визита (до 14:00 — сегодня, с 14:00 — завтра).
- Карточка результата: зарегистрированный вызов с датой визита, отказ с номером 103 или список ошибок заполнения.

## Capabilities

### New Capabilities
- `home-visit`: приём заявки на вызов врача на дом, отказ при неотложных состояниях, назначение даты визита.

## Impact
