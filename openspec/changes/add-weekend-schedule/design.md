# Design

## Context

Дата визита считается в `createHomeVisit` по местному времени Сургута (UTC+5).

## Goals / Non-Goals

**Goals:**
- Отсечка зависит от дня недели; воскресенье пропускается.

**Non-Goals:**
- Праздники и переносы выходных по производственному календарю.

## Decisions

- День недели берётся из той же сдвинутой на +5 часов даты (`getUTCDay()`), что и час заявки.
- Сначала применяется отсечка, затем, если получилось воскресенье, — перенос на понедельник.

## Risks / Trade-offs

- Праздничные дни не учитываются. Это осознанное ограничение до отдельного изменения.
